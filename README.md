# Ensemble Benchmark

**4·5파트 합주 음원을 악기 종류별로 분리하는 음원 분리 대회**의 안내 홈페이지입니다. 대회 소개부터 데이터, 참가 방법, 평가 기준과 베이스라인 결과까지 제공합니다.

## 과제

합주 음원과 분리할 악기 목록을 입력받아, 악기별 WAV 파일을 생성합니다. 같은 악기의 여러 파트는 하나의 출력으로 합칩니다.

> 예: 바이올린 2파트 + 첼로 + 플루트 → `Violin.wav`, `Cello.wav`, `Flute.wav`

출력은 **44,100 Hz · mono · WAV float32** 형식이며, 입력 음원과 샘플 수·시간 정렬이 같아야 합니다.

## 데이터

합성 음원 **SynthSOD**와 실제 연주 녹음 **URMP**를 사용합니다.

| 구분 | SynthSOD | URMP |
| --- | --- | --- |
| 학습 | 363곡 | — |
| 검증 | 24개 혼합음 / 원본 20곡 | 6곡 |
| 평가 | 45개 혼합음 / 원본 41곡 | 10곡 |

데이터 구성은 잠정 목록입니다. 다운로드 자료에는 가공된 학습·검증 음원이 포함되며, 평가(test) 음원은 포함되지 않습니다.

지원 범주는 총 **15개**입니다.

- **현악:** 바이올린, 비올라, 첼로, 콘트라베이스
- **목관:** 플루트, 클라리넷, 오보에, 바순
- **금관:** 호른, 트럼펫, 트롬본, 튜바
- **기타:** 하프, 팀파니, 무율 타악기

피콜로는 플루트, 잉글리시 호른은 오보에에 합산합니다. 색소폰은 평가에서 제외하며, 하프·팀파니·무율 타악기는 SynthSOD에서만 평가합니다.

## 참가 방법

1. 홈페이지의 **참가·평가** 페이지에서 코드와 학습·검증 데이터를 내려받습니다.
2. 제공된 학습 노트북과 평가 노트북을 순서대로 실행합니다. 처음에는 `SMOKE=True`로 실행 흐름을 확인합니다.
3. 모델을 개선하고, 곡 목록의 `target_classes`에 맞춰 악기별 WAV 파일을 준비합니다.

베이스라인은 **SynthSOD X-UMX 기반**이며, 허용된 학습 데이터로 새로 학습합니다. 학습 가중치는 별도로 배포하지 않습니다. 제출 경로·횟수와 실행 자원 제한은 추후 공지합니다.

추가 데이터는 SynthSOD·URMP 이외의 자료만 허용하며, 출처와 사용 조건을 기록해야 합니다. 제공 학습 데이터 외 SynthSOD·URMP 자료와 검증·평가 보호 작품의 원본·파생 자료는 학습에 사용할 수 없습니다. 검증 데이터는 모델·설정 선택에만 사용합니다. 세부 규칙은 홈페이지의 **데이터** 페이지를 따릅니다.

## 평가

**BSS Eval v4**로 SDR·SIR·SAR를 계산하며, 점수가 높을수록 좋습니다. 순위는 다음 종합 SDR을 기준으로 정합니다.

```text
종합 SDR = SynthSOD SDR × 50% + URMP SDR × 50%
```

각 데이터셋의 점수는 작품 단위 집계를 거쳐 악기별 점수를 평균합니다. SIR·SAR는 참고 지표이며, 반올림 전 종합 SDR이 같으면 공동 순위입니다.

현재 리더보드는 **공개 검증 데이터 30개 혼합음의 베이스라인 결과**를 표시하며, 최종 평가 순위가 아닙니다.

## 홈페이지 구성

| 페이지 | 내용 |
| --- | --- |
| `index.html` | 대회 개요와 음원 분리 과제 |
| `data.html` | 지원 악기, 데이터 구성, 추가 데이터 사용 규칙 |
| `participate.html` | 자료 다운로드, 실행 안내, 출력 형식, 채점 기준 |
| `leaderboard.html` | 베이스라인 검증 결과 |

HTML·CSS 기반 정적 사이트입니다. 데이터와 학습·평가 코드 배포 파일은 Git에 포함하지 않고 서버에서 별도로 관리합니다. 다운로드 링크가 작동하려면 사이트의 `downloads/` 경로에서 `dataset.zip`, `code.zip`, `all-downloads.zip`을 제공해야 합니다.
